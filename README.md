# 🎨 StickerBot — стикеры из фото/видео + свои стикер-паки

Telegram-бот на **aiogram 3**: принимает фото и видео, превращает их в стикеры Telegram и раскладывает их в личные стикер-паки пользователя.

## Возможности

- **Фото → статичный стикер** (PNG 512×512, прозрачность + мягкое скругление углов)
- **Видео → анимированный стикер** (WebM VP9, до ~3 сек, до 256 КБ)
- **Свои стикер-паки**: `/newpack` создаёт пак, кнопка «➕ в пак» добавляет туда готовые стикеры
- Кнопка «💾 Отправить как файл» — получить стикер как обычный файл
- Команды `/mypack`, `/add`, `/help`

## Требования

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/) в PATH (для видео-стикеров; для фото не нужен)

Установить ffmpeg (Windows):
```
winget install ffmpeg --accept-package-agreements --accept-source-agreements
```

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Получите токен у [@BotFather](https://t.me/BotFather), создайте файл `.env`:

```
BOT_TOKEN=123456789:AAF...
ADMIN_ID=
```

## Запуск

```bash
python bot.py
```

> У @BotFather обязательно включите **Privacy mode off**, иначе бот не увидит фото в группах
> (в личке и так работает). Для видео-стикеров нужен установленный ffmpeg.

## Как пользоваться

1. Отправьте боту фото → получите стикер и кнопку «➕ в пак».
2. `/newpack` — создайте персональный стикер-пак (укажите латинское имя и название).
3. Любой следующий стикер кнопкой «➕ в пак» добавляется в ваш пак.

## Структура

```
├── bot.py           # бот: команды, хендлеры медиа, добавление в пак
├── sticker_utils.py # конвертация фото/видео в стикеры (PIL + ffmpeg)
├── requirements.txt
├── Procfile         # для BotHost
├── .env.example
└── downloads/       # временные файлы (создаётся автоматически)
```

> ⚠️ `last_sticker` хранится в памяти (словарь). Для продакшена замените на Redis/БД.

## Деплой на BotHost

1. Загрузите код **без** `.env` и без токена в Git-репозиторий.
2. В панели BotHost подключите репозиторий и задайте переменную окружения:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```
3. Убедитесь, что на хостинге установлен **ffmpeg** (иначе видео-стикеры не заработают).
4. Запустите как worker (команда `python bot.py` или через Procfile).
